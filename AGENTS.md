# Learning-note instructions

- Answer every user question in both English and Chinese. Apply this to progress updates and final replies. Keep both versions concise and equivalent.
- For English questions, briefly correct material language issues and provide a natural "Better way to ask" before answering. Skip corrections for isolated words or phrases.
- Explain uploaded experiment results in chat. Create, revise, or copy notes and Notebook files only when the user explicitly requests saving or writing them.
- When writing is explicitly requested, generate or revise paired `note.en.md` and `note.zh.md` files based on the user's thinking process, explanations, questions, and learning drafts. Preserve the reasoning needed to understand the concept and retain only necessary learning content. Do not automatically create a separate raw-draft file.
- Preserve the user's intended meaning. Correct factual mistakes using the actual course material or authoritative sources; explicitly identify corrections or supported additions. Ask about ambiguity that would materially change the meaning.
- Write each document in one language. Use English `README.md` and Chinese `README.zh-CN.md`, with reciprocal relative links at the top. Add reciprocal language links to every `note.en.md` / `note.zh.md` pair. Do not interleave English and Chinese paragraphs in written documents. Chat replies remain bilingual.
- Keep the two note versions aligned in facts, examples, and experiment results. Use simple English and clear Chinese, retaining useful English technical terms.
- Keep workflow instructions, note-generation steps, conversation housekeeping, and generic template prompts out of the notes and README. Use headings only when the actual content needs them. Include only important learning points. Do not invent measurements, screenshots, completed experiments, or answers to unresolved questions.
- Record sources when used. Reread both files after editing to check consistency.
- Keep personal notes in this repository. The course checkout is separate at `../hello-gpu`.
- Do not publish notes or create a remote repository unless the user asks for it.
